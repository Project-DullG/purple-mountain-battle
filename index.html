🎮 기본 진행

보랏빛 산지에 입장하여 적을 처치하고 보상을 획득하세요.

  • 전장 초입부: 적 x0.5, 보상 x1 (입문용)
  • 전장 중심부: 적 x5, 보상 x5
  • 전장의 끝: 적 x30, 보상 x10 (강화석 2배)
  • 무한의 전장: 적 x10, 보상 x10, 끝없이 도전
  • 구역: 5구역마다 중간보스, 10구역마다 보스
  • 스킵: 클리어한 구역까지 50% HP로 즉시 이동

⚔️ 전투 시스템

  • 기본 공격: MP 1 회복, 적이 반격함
  • 스킬: MP 소모, 쿨타임 있음, 일부는 반격 무시
  • 기본 치명타: 10% 확률, 130% 피해 (DEX/LUK로 증가)
  • 기본 회피: 10% 확률 (LUK로 증가, 최대 80%)
  • 치명타 100% 초과: 초과분이 치명타 데미지로 전환

📊 스탯

  • STR (힘): 공격력 +1, HP +1, 치명타 데미지 +0.5%
  • DEX (민첩): 공격력 +1, 치명타 확률 +1%, HP +0.25
  • INT (지능): 마법 피해 +2%, MP +0.5, HP +0.5, 치명타 데미지 +2%
  • VIT (체력): HP +2, 받는 피해 -0.2% (최대 -20%)
  • LUK (행운): 치명타/회피 +0.5%, 보상 +1%

🎭 스킬 (4종류)

  • 강공격: 높은 피해, 쿨타임 2턴
  • 보조: 낮은 피해, 쿨타임 없음, 추가 효과
  • 버프: 일정 턴간 강화 효과 부여
  • 패시브: 항상 적용 또는 조건부 발동
  • 대장간 강화: 캐릭터 무기 +1당 스킬 효과 +5%

✨ 유물

전투 중 획득, 던전 종료 시 사라지는 임시 아이템

  • 등급: 일반 → 고급 → 희귀 → 영웅 → 전설
  • 태그: 공격(빨강) / 방어(파랑) / 특수(보라)
  • 근원 합성: 같은 등급 3개 → 상위 등급 1개
  • 근원 강화: 태그별로 +1당 유물 효과 +5%

🏠 마을 시설

  • 부적 상점: 골드로 영구 스탯 증가 (레벨당 비용 증가)
  • 대장간: 강화석으로 무기 강화 (최대 20레벨, +100%)
  • 숙소: 근원석으로 유물/스탯 강화, 리더보드 확인

💎 자원 획득

  • 골드: 적 처치 시 획득 → 부적 구매
  • 강화석 💎: 보스 처치 시 획득 → 대장간 강화
  • 근원석 🔮: 10구역 보스 처치 시 획득 → 숙소 강화

💾 저장

  • 로컬 저장: 현재 기기 브라우저에 저장
  • 클라우드: 닉네임 + 4자리 코드로 어디서든 불러오기
  • 저장 항목: 레벨, 골드, 스탯, 스킬, 강화, 최고 기록
